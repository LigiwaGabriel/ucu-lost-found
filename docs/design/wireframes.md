# Wireframes (Milestone 1c - 5 marks)
**Owner: Member 4**

## 1. Browse and Search

The browse page allows users to view lost and found items reported around the UCU campus. Users can search for items by name and filter them by category or status. Each item is displayed in a card showing its picture, title, location and status. Users can click an item to view more details.

- **Mobile:** Items are displayed in one column, with the search and filter options arranged vertically.
- **Desktop:** Items are displayed in a grid, with search and filter options arranged horizontally.

## 2. Report Form

The report form allows registered users to submit information about lost or found items. It includes fields for the item name, description, category, location, date, contact information and image where applicable. Users are guided to fill in the required fields before submitting.

- **Mobile:** The form uses one column, making it easy to fill in on a phone.
- **Desktop:** The form is centred on the page with enough space for users to enter information comfortably.

## 3. Report Detail and Claim Form

The report detail page displays information about a specific lost or found item. It includes the item picture, description, location, date and status. Users who believe an item belongs to them can submit a claim by explaining how they can identify or prove ownership.

- **Mobile:** Item details and the claim form are arranged vertically.
- **Desktop:** The item information and picture are displayed clearly, with the claim form below or beside the details.

## 4. My Reports and My Claims

This page allows logged-in users to manage their own reports and claims. Users can view the items they have reported and check the progress of claims they have submitted. Status labels help users know whether a claim is pending, approved or rejected.

- **Mobile:** Reports and claims are displayed as stacked cards.
- **Desktop:** Information is displayed in wider cards or rows for easier viewing.

## 5. Admin Claim Review

The admin page allows administrators to review claims submitted by users. The administrator can view the claimed item, claimant information and ownership explanation. The admin can approve or reject a claim after reviewing the information.

- **Mobile:** Claim information is displayed in stacked sections with clearly visible action buttons.
- **Desktop:** Claims are displayed in rows or cards, making it easier for administrators to compare information and review several claims.

## Design Decisions

### Navigation
The website uses a simple navigation menu with links to Browse, Report Item, My Reports, My Claims and Admin where applicable. On mobile phones, the menu is hidden and opened using a Menu button. On desktop, the navigation links are displayed horizontally.

### Colours and Contrast
The website uses a dark blue colour (#1d3a8a) as the main brand colour, white for backgrounds and buttons, and a light grey background (#f6f7fb). Dark text (#1b1f2a) is used for readability. Yellow is used for keyboard focus, while red and green are used to show error and success messages.

### Keyboard Focus and Accessibility
The website supports keyboard navigation. Users can move between links, buttons and form fields using the Tab key. A visible yellow outline shows which element is currently focused. A skip link is provided to allow users to go directly to the main content.

### Form Labels
All form fields have clear labels so users understand what information is required. Required fields are validated, and error messages are displayed when information is missing or incorrect. Input fields and buttons are designed to be large enough for mobile users.
