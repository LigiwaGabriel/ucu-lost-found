# Member 4 - Contribution and Reflection (Milestone 5d)

## My responsibilities
My responsibility was to work on the frontend foundation of the UCU Lost and Found website. I was responsible for helping create the website layout, navigation, styling and user authentication pages. I also worked on the wireframe documentation.

## What I built (files, features, commits)
I worked on the following files:

- `client/src/App.jsx` – helped set up page navigation and routes.
- `client/src/components/Layout.jsx` – worked on the website header, navigation menu and footer.
- `client/src/pages/Login.jsx` – created the login page.
- `client/src/pages/Register.jsx` – created the registration page.
- `client/src/styles.css` – worked on colours, layout, responsive design and styling.
- `docs/design/wireframes.md` – prepared documentation for the website wireframes.
- `docs/reflections/member-4.md` – wrote my contribution and reflection report.

I also prepared my work for GitHub using Git commands to add, commit and push changes.

## Decisions I made and why
I chose dark blue and white colours because they make the website look clean, professional and easy to read. I used simple navigation so users can easily find different pages. I also made the design responsive so it can work on both phones and computers. Form labels and error messages were included to help users enter correct information.

## Challenges and how I solved them
One challenge was understanding how different pages connect and how navigation works in React. I solved this by learning about routes and using React Router. Another challenge was making the website work on different screen sizes. I used CSS media queries to adjust the layout for mobile and desktop screens. I also worked on form validation to prevent users from submitting incomplete or incorrect information.

## What I learned / what I would do differently
I learned how to use React, JSX, CSS, React Router and GitHub in a project. I also learned the importance of responsive design, accessibility and teamwork when developing a website.

If I had another chance, I would spend more time testing the website on different devices, improve the wireframes before coding and communicate more with my teammates to make sure all parts of the project work together properly.
