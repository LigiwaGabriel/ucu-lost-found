LIBRARIES AND CODE 

The group built the UCU Campus Lost and Found System using the following open-source packages, runtimes, and tools:Backend (server/package.json): express (REST API routing and middleware), mysql2 (MySQL promise pool and transactions), bcryptjs (password hashing), cookie-parser (cookie parsing), dotenv (environment variable loading), express-rate-limit (request rate limiting), helmet (HTTP security headers), multer (multipart file upload handling), and supertest (HTTP API integration testing)Frontend (client/package.json): react and react-dom (user interface components), react-router-dom (client-side routing), and vite with @vitejs/plugin-react (development server and production build bundling)Runtime, Database & Testing: Node.js (v18+/v22), MySQL 8 (InnoDB) / MariaDB, and Playwright / headless Chromium for browser verification   References (IEEE)[1] OpenJS Foundation, Express: Fast, unopinionated, minimalist web framework for Node.js, v4.19.2.
